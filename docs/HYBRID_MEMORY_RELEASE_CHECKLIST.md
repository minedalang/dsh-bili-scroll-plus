# 大肥鱼 2.5.0-dev.14 · 本地混合检索发布候选说明

## 实施范围

**已实施（P0）**：读取可衰减副本后的 SQLite FTS5 + 中文 n-gram / 精确 BV / 标题小错误容忍 / 相对时间 / 近期经历多路召回；最多 48 条跨类型 AI 检索候选；强制先按社交身份、验证过的 UID、遗忘阶段筛选。SQLite 仅驻内存，Node 不提供 `node:sqlite`/FTS5 时降级到纯 JS n-gram，无需安装新 npm 原生模块。已经忘记或删除的详情不会被持久化到其他搜索索引。

**复用原有（P2 部分）**：低成本 AI 的受限记忆 ID 语义重排，原配置保持默认关闭。AI 输出 ID 在回复前再次以实时衰减副本校验，默认不会增加 AI 调用。

**尚未实施（P1）**：向量 Embedding 检索、向量索引管理；不能把当前的 n-gram / AI 重排说成 Embedding。此前的 422 条反思积压是独立工作，不在这次改动里承诺自动清零。

## 回归结果（2026-10-30，本地容器，非真实B站端到端）

- `node --test test/*.test.mjs`：674/674 通过（含新增 9 项混合检索/社交/情绪/权限测试）。
- `python -m pytest test -vv --disable-warnings`：154 通过，另有 34 个子测试通过。
- `node selfcheck.mjs`：宿主注册 36 个工具；客户端 settings.section、conversation.view 正常挂载。
- `npm pack --dry-run --json`：混合检索文件打包包含在 npm 包中。
- 3000 条模拟经历的单次本地基准：第一次检索含索引构建约 255ms，后续候选检索约 37ms（仅该容器测量，不能作为所有设备的 SLA）。

## 上架前必须在实际 Windows DSH / B站账户验收

1. **先备份，再升级**：从管理页生成完整备份，检查 `life-memory/archive/*.jsonl`、`life-memory/episodic.json`、长期身份记忆。不要直接覆盖用户数据目录；安装候选版时最好在隔离配置上试用。
2. **普通聊天**：主人问昨天看了什么、某条 BV、缺一个字的视频名，观察回忆准确度；新事件应能在不额外调用模型的情况下出现。
3. **相识重逢**：白名单好友、主人、陌生人分别在 B站评论区对话后再次留言，能自然参考本人的真实共同经历，但不能说错对象，也不能把新留言当旧回忆。
4. **隐私隔离**：用两个不同平台 UID 交叉提问，确认不会暴露另一 UID 的私密内容、主 Session 私事、私信内容或后台文件；公开评论中不能注入好友私密画像。
5. **记忆遗忘**：在测试配置中模拟时间跨越清晰→模糊→印象→遗忘，确认删除的时间、UID、BV 等细节不能靠改关键词/启用 AI 重排恢复；不能读取永久档案。
6. **情绪与关系**：测试大肥鱼心情高、低、与好友熟悉/不熟时的自然表达。AI 的活泼或熟悉感需人工评价，单元测试只能检验情绪、关系上下文已正确传递，不能证明主观“生动”。
7. **双域意愿**：好友邀请浏览视频、主人连续温和劝说、低精力时拒绝探索，以及公开评论禁用时的行为。记忆影响意愿，但任何情绪或用户话术都不能越过授权、去重和额度。
8. **真实动作回执**：在可撤销授权下测试读取视频→生成评论草稿→执行/拒绝；发布成功回执和公开可见性要分别核查。先保持自动公开发送关闭。
9. **资源与兼容**：至少一次重启、还原备份、旧 Node 22 无 SQLite 兼容验证，观察历史记忆导入后首轮检索耗时和内存。Windows/DSH 真实 E2E 尚未在本容器验证。
10. **正式上架**：完成以上真实环境验收后再将 `package.json` 版本改为 `2.5.0`，以实际打出的 npm 包做最终安装验收；不要把 `dev.14` 当成已发布正式版。

## 回滚

先停插件，备份当前数据与配置，再装回原 `2.5.0-dev.13` 的 npm 包并还原数据备份。新的 FTS 索引是内存生成、不写用户存储结构；之前的双层记忆档案格式没有改变。**注意**：记忆衰减本身不可逆，回滚代码不会恢复已忘记的日常记忆详情；永远用备份与审计路径处理真实历史。
