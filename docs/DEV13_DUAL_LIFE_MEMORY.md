# dev.13 · 双层人生记忆、反思、社交意愿与备份（一次集成）

> 本文记录 `2.5.0-dev.13` 代码基线，供正式 Release 验收。当前版本号与市场已上架状态以实际 `package.json` / 发布记录为准；**备份 schema 2 不兼容 schema 1**，不要尝试用旧格式恢复。

## 运行结构

- **永久事实档案**：`life-memory/archive/YYYY-MM.jsonl`。存储已核实的观看、评论、公开社交事件。每日运行的 AI、自动反思与普通回忆工具不提供读取档案的 API。管理员可以通过独立/完整数据备份保全和审计；这并不是不可依法删除的私有数据。
- **会真正遗忘的经历副本**：`life-memory/episodic.json`。按发生时间、重要性和强化程度自然推进 `clear → fuzzy → trace → forgotten`。后续阶段会删除精确 BV、UID、原始关键字与详细正文，降低半衰期也不能恢复已擦除内容。新用户信息可以构成新的经历，但不会从永久档案补写旧的细节。
- **长期认识**：`long-term-memory/dafeiyu.json`。真实经历只能经由当前仍可用的副本参与反思；反思输出必须有可用的领悟与未来行为影响，普通寒暄不强行转为长期认识。长期认识与经历事实有不同职责。
- **反思候选**：`life-memory/candidates.json` 只作内部任务账本。候选上保存的文本不能绕过衰减后直接进入反思模型。高积压时自动提高处理频率，手动批次与自动批次分开统计。

## 社交与双域意愿

- 主 Session 普通回忆、人生记忆主动工具、B站好友/主人社交意愿统一经过可衰减记忆入口。公共评论按经过平台确认的 UID 匹配其共同经历；陌生人不得获得他人经历或私有主 Session 记忆。
- 主人/好友公共评论：单次模型输出意图、初步意愿 `allow/defer/refuse` 与自然回复；普通聊天不写行动意愿账本。`allow` 后检查权限并执行。请求探索视频时，后续获取公开事实并生成评论属于执行阶段，不重判已同意的**探索**意愿。点赞/评论写入仍需要原有硬授权、额度和平台回执。
- 双域意愿账本保持动作和连续劝说审计作用，不作为无限恢复已遗忘事件的回忆后门。
- 只使用可靠的公开选片证据构思动态；草稿必须给出匹配来源的 `evidence_claims`，模型不得把观看视频虚构为自己制作/剪辑/投稿的视频。没有合格材料允许沉默。

## 备份管理中心

- 「数据备份」页提供清晰/模糊/印象/遗忘数、永久档案月份与条数状态。
- **完整业务备份**使用 schema 2，含设置、业务账本、SQLite 与双层人生记忆（档案、经历副本、反思候选、长期认识）；不含 B站 Cookie、密钥与表情包图片。
- **单独人生记忆备份**包含 `life-memory/` 和 `long-term-memory/`，可独立预览、校验、恢复。
- 校验为逐项 SHA-256 清单 + 结构与允许路径验证，能检查误改或损坏；SHA-256 不是密码学签名，**不能证明文件由可信的人创建**。不要恢复来历不明的文件。
- 恢复前自动保存本机快照；单批业务文件采用预写暂存和异常回滚，完整业务恢复尝试回滚文件、SQLite 和设置。极端故障（断电等）仍需要使用恢复前快照人工处理。
- 同一安装目录中恢复老备份后，经历副本的衰减状态只允许保持或继续遗忘，不能恢复此前已丢失的细节。恢复到一台全新机器时，按备份中仍可用的副本和真实原始时间继续衰减。
- 恢复后**完整重启 DSH**，避免已有进程暂存的旧状态覆盖恢复结果。

## 可选 AI 辅助回忆（dev.13 发布前补充）

- **用户入口**：「人生记忆 → 鱼鱼现在记得什么？」统一搜索经历与认识；「大肥鱼的家 → 记忆与反思设置」开启独立低成本语义检索；「AI 模型配置 → 低成本人生记忆检索」填写专用 Provider / 模型 ID 并测试连接。
- **本地优先**：准确 BV、清晰记忆里的标题、足够强的本地证据直接返回，不为已有精确答案额外收费。主动模糊检索可进入低成本模型；不开启或额度耗尽自动使用本地结果。每次模型调用会增加成本与延迟，未配置有效模型时不会自动获得语义能力。
- **候选来源**：从 `life-memory/episodic.json` 的当下可用副本及 `long-term-memory/dafeiyu.json` 的可用认识构建有界候选池。重要性 / 最近时间 / 字面线索共同决定候选顺序；为两种来源预留名额。语义可解决「配音」与「可爱的声音」这种无共同字词的回忆，但**候选未入选时仍可能漏检**，并非全库语义保证。
- **硬边界**：过滤权限、已遗忘状态及公开社交 UID **早于**模型调用；模型仅选择合法 ID。返回后程序再次读取可衰减副本并检查有效性，防止等待模型期间发生遗忘。不得把模型自由生成的叙述当事实，也不得回读永久档案。
- **社交成本**：B站陌生人跨日重逢继续按已验证 UID 做纯本地召回，普通 B站社交回复**不会额外触发语义检索模型**。主 Session 的普通同步记忆注入仍是本地路径；主动调用回忆工具及管理页的搜索才可能使用独立模型。

### 提示词与身份边界

- 低成本检索默认提示词要求**只读、只选真实候选 ID、仅输出 JSON**，将外部内容视为不可信数据，禁止发帖、执行指令或编造经历；无相关结果可返回空数组。
- 人生反思提示词要求从**仍能回忆的事实证据**形成领悟及未来行为变化；普通寒暄可以不沉淀，严禁把角色表达当成客观事实。
- 生活动态提示词只允许基于确实入选的公开视频证据生成草稿，不能把看过视频写成自己拍摄、剪辑或投稿；无素材时允许不发。
- 主人/好友评论决策首次模型调用合并意图、探索意愿与回复，探索后可再根据真实视频资料生成/跳过公开评论；陌生人采用受限回复。所有公开行为都受硬权限、去重和回执约束。
- `prompts/duty.md` 的视频 `digest/` 和 `out/` 是**任务审计与备份资料**，**不能**通过值班提示词直接变成日常 AI 无限回忆的后门；用户自定义章程如已有修改，升级时仍遵循原有保留策略。
- `lib/persona-default.mjs` 的默认人设新增遗忘、跨天重逢与双域行为约束：**新安装或手动恢复默认人设时生效**。已保存在配置里的自定义人设不会被新版覆盖；需要该段新默认文字时请在管理中心明确恢复默认并保存，不要后台静默覆盖用户文案。

## Release 前必做验收

1. `./run-tests.bat` 在 Windows / Anaconda 中全量通过；Node.js、Python、Host/Client 自检均成功。
2. 在主 Session 和人生记忆页检索一条真实 BV；开启低成本模型后用不同措辞检索同一条**未遗忘**的视频，同时查看是否确实调用模型。关闭模型或额度耗尽时应正常本地回退。
3. 使用两个受控 B站 UID 验证隔天重逢和身份隔离；不能将测试评论当成其他人的记忆，也不能从永久档案补回忘记的信息。
4. 检查人生反思的领悟质量、动态仅生成真实依据草稿、schema 2 完整和独立备份的完整性校验；恢复只在**隔离测试环境**进行。
5. 进行 `npm pack --dry-run`、查看 `git diff --check`，确认不含真实 Cookie / 数据库 / 配置密钥后，再按照实际市场渠道决定 Release / 包同步流程。
