# dev.15 管理中心界面重构 · 发布候选验收

基线：`2.5.0-dev.14`。目标：`2.5.0-dev.15`。本次仅调整管理中心布局与一个拆分的主 Session 保存动作；不迁移用户数据、不修改长期记忆、好友、社交 Agent、情绪引擎、后台授权或后端配置字段。

## 页面分区

- **大肥鱼的家**：真实可用记忆、模拟情绪与熟悉好友概况（只读）；连接及选择当前主 Session。点击卡片跳转对应完整功能页。
- **人生记忆**：经历搜索、长期认识、情绪走势、兴趣、待办、关系、反思与时间线；已移出情绪驱动的主动对外分享授权和独立后台调度配置。
- **社交互动**：好友名册、主动回访、主人私信 Agent、主人公开评论与情绪驱动的主动分享授权。独立授权仍须明确保存；默认权限不因升级而变化。
- **插件设置**：记忆与检索/反思参数、主 Session 同步频率、待办调度；模型 Provider/ID 仍只在 AI 模型页编辑。
- **最近评论 / 后台私信**：记录与申请前置显示，规则与权限仍有独立入口和原来的保存按钮。
- **每日诊断** 在导航显示为「运行诊断」，后端接口和日志路径不变。

## 修改了哪个保存动作？

- 原 `main-session-save` 写入当前房间连接信息及同步频率。现在只写 `mainSessionBridgeEnabled`、`mainSessionId`、`mainSessionAutoSync`；无房间时仍由原接口 `clear: ['mainSessionId']` 处理。
- 新增 `main-session-sync-save`，只写 `mainSessionSyncMinutes`、`mainSessionDailyBatches`、`mainSessionBatchSize`、`mainSessionIncludeComments`。这样不会在不同页面之间静默覆盖对方刚调整过的设置。
- 记忆反思、情绪、社交、好友、评论、私信、自主待办的保存 API 和配置键未改变；原有 HTML ID 一个也没有删除或复制。

## 验收方案

1. 在 `2.5.0-dev.14` 基线上 `git apply --check`，再应用补丁；升级前备份配置及 `$DSH_HOME/bili-duty/`。
2. 打开管理中心，无 URL tab 参数时进入「大肥鱼的家」；每个卡片仅展示实际已有的只读统计，缺失数据提示不可用，不伪造记忆。
3. 切换「插件设置」，分别保存检索配置与经历同步频率，刷新核对持久化值。切回「家」修改主 Session，不改变之前保存的同步频率。
4. 切换「AI 模型」，检索模型的 Provider、模型 ID、思考深度可加载/保存，仍只有一套输入框。
5. 「人生记忆」能查经历与体会、心情、兴趣、待办、关系和反思；「插件设置」的高级参数不再出现在家里。
6. 「社交互动」情绪主动回忆及两个主动分享渠道默认仍关闭；好友和唯一主人 UID、主人评论 Agent 权限均原样保留。仅点击“预览”不能真的发送。
7. 评论页先显示评论记录，私信页先显示会话/申请；旧监听开关及权限分项保存后刷新一致。
8. 使用真实 Windows DSH，检查深色模式、窄屏、浏览器刷新和 `?tab=settings` 深链接；验证宿主设置页挂载与关闭/重启后恢复。
9. 实测 B站只读好友互动、陌生人与好友 UID 隔离、实际评论/私信在授权关闭时不会发送；如需开启真实发送，使用测试账号逐一手工授权验证。

本地自动测试可验证页面结构、浏览器 UI 行为与后端加载，但不能替代真实 DSH / B站登录环境的上线前验收。
