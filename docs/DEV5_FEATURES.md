# dev.5 社会认知功能说明与限制

> 开发版 `2.5.0-dev.5` 的实现说明；真实 DSH Desktop 与 B站端到端行为仍需验证。此文件用于代码维护和验收，不代表已经发布稳定版本。

## 现有能力

- **陌生人私信灵感**：只有开启监听及灵感开关后，新收到的明确、安全视频主题才成为 7 天有效的匿名候选；每个来源和每日总数都有限额。候选不会直接产生待办、聊天资格、点赞、私信或公开 @ 权限。
- **好友观看邀请**：好友在私信中指定真实 BV，或在被许可的 @ 通知中指向当前视频并邀请“有空看看”，可生成 14 天有效的只读候选。大肥鱼可以不处理它。
- **模拟情绪参与选择**：在主人额外允许时，好奇度、活力和时间冷却条件影响是否审阅一条视频的资料；`inspected-metadata` 不等于播放或完整观看。
- **好友推荐许可**：好友能够表达对某个视频、主题、公开 @ 渠道或全部主动推荐的拒绝；明确重新订阅时可恢复。原有 UID 核验、额度、冷却和发送前复核仍适用。
- **主人评论受限操作**：仅对平台核实的主人 UID 及当前视频执行显式授权的点赞、草稿或明确正文发布。公开短回执是单独可选权限，不引入主人私信或主 Session 私密上下文。

## dev.5 对旧「临时视频心愿」的处理

旧版获批私信用户的视频心愿是一套独立的“搜索关键词 → 临时公开 @”行为，含审核、人工补录、发送次数和独立 Python 占位代码。该流程已整体退出运行：

- 管理中心不再提供旧列表、审核、补录、发送次数设置。
- 刷视频 Agent 不再读取旧心愿或附加 `temporary_wish_id`；B站评论工具也不再接收这个参数。
- 已保存的心愿在旧私信状态被读取时标为 `legacy_archived`，不删除原记录；发送回执目录只用于历史备份，不重放。
- 不自动迁移旧授权到新候选池。新的陌生人灵感和好友邀请必须由符合条件的**新消息**产生。
- 获批用户的正常私信聊天与额度仍属于原有独立系统，不因旧心愿功能退役而撤销。

## 限制与安全边界

- 身份与视频目标由 B站收件数据和当前通知上下文确定，而不是由用户文字声明。
- 模拟情绪决定是否考虑候选，不扩大社交身份和工具权限。
- 公开评论执行结果不确定时不得重试，也不得编造成功。
- 当前受限评论 Agent 使用明确句式识别，不能保证理解任意复杂口语。
- 新社会认知仍在「人设与好友」中的相应设置和状态区域；不是独立顶层页面。
