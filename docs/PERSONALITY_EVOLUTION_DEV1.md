# Personality Evolution 2.6.0-dev.1（开发预览）

此功能仅面向 `dev` 体验者，默认关闭。它不是新的人生记忆系统；原始人生经历仍只记录在 Life Memory 2.0，日常人格成长输入只能来自其当前还存在的、会衰减的副本。禁止从永久档案、日报或候选池恢复旧细节。

## 使用方法

在「大肥鱼管理中心 → 🏠 生活与成长 → 🌱 人格成长」开启。开启后，下一次正常人生反思会在**同一次模型调用**中选择性输出 `trait_proposals`。不会追溯重跑老反思，也不会每条消息增加一次 AI 调用。长期记忆反思关闭时，成长人格也不会产生新候选。

## 数据设计

`$DSH_HOME/bili-duty/personality-evolution/v1.json` 保存启停状态、少量固定特质的方向和匿名证据引用（SHA-256 截断）、变化时间线以及提示词引用次数。不保存 BV、UID、视频标题、评论或原始私人消息。当前特质：结识新朋友意愿、探索陌生事物、表达想法、交流耐心、社交边界意识。模型只能从有限的已知特质中选择，不能添加指令、权限或新系统提示词。

一次经历只可计作一条证据。当前至少需要**三条独立经历、跨两个日期、方向一致**，才进入「发展中」并作为有边界的建议出现在提示词中；单次短暂情绪不能改写人格。相反经历会抵消方向。主人可以暂停或清除特定成长记录；初始人设、手动批准的表达规则和所有权限保持独立。

## 当前已完成与尚未完成

- 已完成：原有反思中的候选提取与校验、可衰减副本二次校验、独立的成长倾向聚合、谨慎的提示词使用、时间线、启停与清除、全量业务与人生记忆备份包含成长状态。
- 未完成：实际发送/选择结果与成长特质的独立因果验证；历史人格变化的更丰富可视化；从开放文本自动发掘新的个性特质；完整跨时间人格一致性评估。
- 明确不包含：本地视频视觉理解、Ollama、人格自动批准外部写入、主 Session 工作可靠性降级。

管理界面的「提示词引用次数」仅表示某项正在发展的特质被加入了后续模型上下文，**不是** B站回复成功回执，也不能证明特质造成了某次行为。后续开发应基于真实动作回执/拒绝结果建立单独验证层。

## 主 Session 工具兼容修复

本版本同时补齐 `dafeiyu_life_recall` 和四个 `dafeiyu_todo_*` 工具的 `output.schema` 与 `output.render()`；修复旧版真实宿主注册时读取 `undefined.render` 导致五个工具无法挂载的问题。不修改 MCP、对外操作授权和既有记忆/待办数据。

## 主 Session 生活汇报避免无意义唤醒

自动经历汇报在有新事件且 DSH 提供 `agent.inject()` 时，采用非唤醒注入，不再通过 `followup()` 每隔一小时启动一轮模型来回答“收到生活经历更新”。没有注入接口时保留待汇报队列并在管理页状态中提示，不自动改为唤醒发送。主人点击“现在把新经历告诉主 Session”则保留即时回复语义。此变更不修改人生记忆衰减、权限或现有历史数据；`API key is invalid` 等其他模型请求错误仍需要核对宿主 Provider 配置。

## 同版跨模块完整性修复

- 普通评论和主人／好友 Agent 的成功回执统一补充到 `confirmed-comment-recipients.json`；管理页仍只根据 `seen.md`／月度归档列出真实评论，不根据索引创建新评论。
- 跨文件身份冲突不猜测、不选边；只按精确 BV + 出站 rpid 定位，对方昵称与 UID 在没有可靠来源时留空。旧账本保持只读兼容，恢复信息仅限真实已保存的值。
- 生活动态每日公开额度 0–10 可在动态创作页面直接设置，和「次数与额度」使用同一 `dailyDynamicDailyLimit` 配置。自动构思采用独立的每日调用次数与最少 60 分钟间隔；原有 SQLite 发布闸门继续控制实际发布。默认 1，不自动增加公开动作。
- 所有新设置与业务账本继续纳入原有备份。开发版不自动迁移永久档案、不能通过人格成长扩大公开权限。

## 沙盒快速模拟（仍属 2.6.0-dev.1）

管理中心「🏠 生活与成长 → 🌱 人格成长」点击「🧪 沙盒模拟成长（只预览）」，即可使用**虚构事件**展示从萌芽、发展中、证据冲突到反向调整的人格轨迹，并预览形成的提示词片段。**不要求开启真实成长开关**。

沙盒通过只读 `/api/bili-duty/personality-evolution-sandbox` 提供静态虚构事件的本地计算结果，与真实反思共用证据去重、阈值、阶段和上下文生成逻辑。不调用任何模型，不读取实际 Life Memory，也不会修改配置、数据文件、待办、评论或生活动态。预览期间真实开关和清除按钮不可操作，点击「退出沙盒」返回真实记录。沙盒展示的事件与人格变化均不代表鱼鱼已经经历或形成这些特质。

## 连续模拟沙盒（仍属 dev.1）

在「🏠 生活与成长 → 🌱 人格成长」点击「🧪 播放模拟成长」后，每隔约 1.4 秒推进一段**虚构**经历，展示人格萌芽、强化、相反经历产生矛盾及方向修正。可暂停、单步、重置、调速；刷新后仅恢复此浏览器会话的模拟进度。

沙盒每次通过只读 GET 接口，根据模拟步数在内存中重演与真实反思共用的人格归纳规则；超过 96 段时仅保留最近 96 段作为模拟证据窗口。不会读写真实成长档案、生活记忆、模型配置或 B站数据；浏览器 sessionStorage 只存放模拟步数与播放状态。

## dev.1 同版迭代：真实公开互动质量评估（不升级版本号）

- 公开评论通知先进入 Life Memory 的 `social` 可衰减经历；**只有鱼鱼真实发送回复并获得成功回执**，才将该次社交列为待反思候选。普通问候不会自动加分，失败回复不会标记为已交流成功。
- 继续复用**同一次**人生反思的模型调用，额外返回互动反馈（积极 / 消极 / 不明确）、强度、置信度、以及被引用的对方原话。模型的主观评价只是候选，不能自证聊天愉快；本地再从尚清晰的真实副本核对已回复标志、原话连续片段、反馈线索和观众角色。缺乏依据直接拒绝。
- 正向反馈需要对方原话包含明确的积极线索，不能只写“你好”；“更愿意结识陌生人”不能凭视频选择、自己发的评论或主人夸奖而产生。每位观众、每项特质、每天最多计一条；正式成为发展中须来自至少两位不同**陌生观众**、跨两天的至少三段独立互动。
- 单个成功回复不等于完整多轮对话，因此单次强度最多按中等权重计算。当前权重按可信程度乘以有限强度（约 0.45～1.25），而非所有事件固定 +5。人格仍是模拟的行为倾向，不是对真正情感的测量。已有旧版人格 JSON 继续按原有正反方向读取，新字段兼容默认值。
- 人格状态保存去标识化的观众关联哈希及本地随机盐，不保存明文 UID、原评论或全文引用。模糊/遗忘后的经历不会继续产生新证据；原有永久档案不会被重新用来补分；开启人格功能时才会建立盐值。
- **沙盒**使用预先编写的虚构对话和虚构评估结果，调用与真实成长相同的本地核证及加权器；不请求模型、不触碰真实记忆文件。页面中的“影响分”是规则估算，不能理解为实际心情分数。未来如需测试模型独立判读，需要单独设计经过主人明确授权的演示模式。
- **未完成：**在下一次真实社交选择中量化人格因素的独立影响及实际结果反馈（目前提示词引用仍不是行为验证）；也未将未经许可的私信自动作为成长证据。此阶段优先保证真实经历接线、弱证据不污染人格与可解释的有限幅度。
