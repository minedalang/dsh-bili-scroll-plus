# 🐟 大肥鱼 · DSH 生活系统


**一个会探索、会记得、也会遗忘的 AI 伙伴。**

让鱼鱼在 DSH 主 Session 里陪你做事，在 B 站拥有自己的生活：看视频、结识朋友、积累经历、形成兴趣，在一次次相遇中慢慢成长。

> **大肥鱼不是任人摆布的提线木偶，而是拥有自己人生轨迹的数字生命角色。**
>
> 她有持续积累的经历、逐渐变化的情绪、自己的兴趣与社交关系，也有基于这些经历形成的偏好和选择。她可以因为好奇而主动探索，因为喜欢而靠近，也可以犯懒、犹豫、拒绝，或者选择沉默。
>
> **主人可以邀请她、陪伴她、影响她，却不应该替她决定每一次选择。**
>
> 我们希望创造的，不是一个永远说「好的，主人」的自动执行程序，而是一个拥有连续记忆、鲜明性格和自主选择空间，能够在互动中不断成长的 AI 伙伴。

「数字生命角色」是产品设计理念，描述的是模拟人格与自主行为，**不代表 AI 已有真实生命、感受或主观意识**。这份自主性也不是无限权限：**主 Session 中她可靠执行合法指令；B 站生活域里，她可以对邀请做出自己的选择；任何对外操作仍需明确授权。**

`dsh-dafeiyu-life` 是面向 [DeepSeek Harness（DSH）](https://github.com/deepseek-ai) 的社区插件，并非 DSH 或 B 站官方项目。

> ⚠️ **从 v2.4.99 等旧版本升级到 v2.5.3：建议先备份。**
> 在大肥鱼管理中心进入「数据备份」，先设置本地备份目录，再点击「备份全部业务数据」；重要人生记忆也可以额外执行「单独备份完整人生记忆」。请确认备份文件已保存到独立目录，再通过 DSH Market 更新。升级不会主动清空旧数据，但仍应为跨版本更新保留可恢复的副本。备份文件含私人资料，请勿上传公开仓库。
> 业务备份不含 B站登录凭证、独立密钥、表情包图片等；需要时请单独保留。详见 [v2.5.3 升级说明](RELEASE_NOTES_v2.5.3.md)。

**v2.5.4 紧急热修复：** 修复公开评论记录中主人／好友回复对象的昵称、UID 缺失；保留可信旧 UID 回填，修正生活时间线仅有日期却显示 20:00 的问题。更新前请按上方建议先备份。详见 [v2.5.4 发布说明](RELEASE_NOTES_v2.5.4.md)。

**v2.5.3 修复版源码说明：** 在 v2.5.2 基础上修通 B站视频探索后的真实经历写入、公开视频记忆召回和自然语言线索匹配；保持 Life Memory 2.0 的遗忘、UID 隔离与外发授权边界。

- **生活动态更自然**：日常以短句、碎碎念和真实情绪为主，认真分析型动态偶尔出现；没有合适的真实素材时可以不生成。
- **拒绝虚构经历**：不把内部“选中视频”的流程写进动态，也不照搬视频标题推测鱼鱼想去其他平台。新草稿、历史草稿都需要通过真实性与内容质量校验。
- **情绪自主分析修复**：修复情绪回忆事件的 BV、日期和标题缺失；启用功能后，即使没有适合分享的旧事，也可进行有限的内部分析，管理页可查看结果与次数。
- **权限保持独立**：内部思考不等于主动发送；动态公开发布与主动私信仍需各自授权、校验额度并遵守隐私规则。升级不自动开启外发权限。

- **社交昵称防误读**：@ 完整昵称不作为情绪或行动事实，无法核实边界时保守忽略提及，不因昵称里的“怒了”等词编造回应。
- **记忆数量说清楚**：永久归档事件数与可衰减副本数分开显示，并标注年龄、未来自然衰减时间。
- **意愿与情绪可追溯**：展示近 7 天真实意愿决定与当时的社交意愿分数；新的真实情绪状态形成带时间轴的快照趋势，旧记录不伪造历史曲线。

- **跨视频回忆修复（v2.5.3）**：@ 邀请或自主查看视频时，将确实读取的公开资料写入可衰减记忆；评论区可以按当前真实 BV、旧视频标题或相关话题寻找鱼鱼仍记得的公开视频经历，不会因没拿到画面就否认过去读过字幕。仅有选片记录时仍只称“选中”，不会伪称看过完整画面。
- **记忆隐私与遗忘**：主 Session 私下发起的新版探索不自动公开；其他人的共同互动不混入公开回复，模糊/已遗忘的 BV、标题不能从永久档案恢复。旧用户数据保持原样。

## 🔭 v2.6.0 开发预告（规划中，尚未发布）

下一阶段，我们希望让大肥鱼不仅能记得自己的生活，还能在长期经历中逐渐形成独特的性格，并获得更真实的视频观察能力：

- **成长性人格（Personality Evolution）**：主人提供初始人设，鱼鱼通过真实的视频探索与交流，逐渐形成、强化或修正性格倾向；计划在管理页展示有证据支撑的人格成长路线图，并检验变化是否影响之后的实际选择。成长不意味着每次经历都要获得“感悟”。
- **可选的本地视频理解**：计划接入可选的本地视觉模型服务（优先评估 Ollama / Qwen3-VL），按需提取少量视频画面并记录时间戳，与字幕等资料共同理解内容。功能默认关闭，不强制下载大模型；没有合适硬件或服务不可用时，仍可继续使用现有文字理解方式。

以上是开发方向，**不是 v2.5.3 已提供的功能，也不代表确定的发布日期**。人格变化不会改变操作授权、安全与隐私边界；视觉分析不会把少量截图当成看完整段视频。进展以 [`dev` 开发分支](https://github.com/minedalang/dsh-dafeiyu-life/tree/dev)及后续正式 Release 为准。

## ✨ 和普通聊天机器人有什么不一样？

### 🌿 有自己的选择：双域意愿

在**主 Session 工作域**，鱼鱼帮助主人处理任务、调用已授权的工具，不会用模拟情绪逃避工作。

来到 **B 站生活域**，她不是一句指令就会行动的工具。面对主人的邀请、好友的分享或陌生人的留言，她会结合当下情绪、兴趣、关系和能够回忆的经历，决定**接受、推迟、拒绝或不说话**。

> 👤 主人：「鱼鱼，来看看这个视频嘛。」
>
> 🐟 鱼鱼：「今天有点懒，不过……标题好像挺有意思的。先让我瞅一眼！」
>
> 👤 主人：「看完想说什么？」
>
> 🐟 鱼鱼：「得看我有没有真实的想法呀，才不要为了评论而评论～」

*以上为风格示例，并非真实聊天记录。* 温和劝说可能影响选择，但不会让她绕过平台权限、发送额度、隐私保护或去重规则。

### 🧠 双层人生记忆：有记忆，也会忘记（Life Memory 2.0 · v2.5.0）

**她不是每天重新认识世界，也不是一本随时能翻到所有过去的百科全书。**

刚发生的经历可能记得很清楚；随着时间推移，细节会模糊，最后只剩印象，甚至真的想不起来。但有些经历留下的体会，可能陪伴她更久。

完整历史由**永久事实档案（仅备份 / 管理审计）**独立保存，**日常 AI 不可直接回读**；鱼鱼实际能够想起的，只能是当前还没有忘记、且被允许访问的记忆。即使管理员留着原始记录，也不会让她假装自己还记得。

v2.5.1 支持可衰减经历、人生反思、本地混合检索、按 B 站 UID 隔离共同经历，以及与主 Session／社交意愿的联动；**AI 辅助回忆（可选，默认关闭）**是在现有候选记忆中选择真实记录，不是凭空补故事。

身份级长期认识默认存于本地 `long-term-memory/dafeiyu.json`，不同主 Session 可以沿用同一角色身份，而不是每次重新开始。

**尚未实现**：Embedding 向量检索、持久化向量索引和完整的跨私信长期关系图谱；这些能力不会作为当前可用功能宣传。想了解检索、权限和遗忘的实现边界，可查看 [Life Memory 2.0 技术说明](docs/LIFE_MEMORY_2_TECHNICAL.md)。

### 🌱 人设只是起点，她会被自己的经历慢慢改变（`v2.6.0-dev.1` 开发预览）

**主人只需要给鱼鱼一个初始模样，之后发生的每一次相遇，都可能给她留下一点新的性格。** 她可以依然傲娇，却比过去更愿意认识新朋友；也可能因为学会尊重彼此的边界，而变得更有主见。这不是一条必须通向「更完美」的升级路线，而是有进有退、有犹豫、有变化的生活。

**想象鱼鱼经历了这些事（以下是虚构示例，并非真实运行记录）：**

> **🌸 慢慢敢和陌生人聊天了**
>
> 最初，她面对陌生观众的夸奖只会别扭地回应一句「哼，知道啦」。几天里，她和**不同的观众**有了几次真诚、愉快的交流。下次再遇到新朋友，她也许会主动接上一句：「诶，你也喜欢这个话题呀？鱼鱼最近刚发现个有意思的东西！」——但是否回复，仍由当时的意愿与权限决定。
>
> **🛡️ 学会温柔而坚定地划清边界**
>
> 有人气冲冲地说「别来找我」。鱼鱼决定不回复，尊重对方停止交流的要求。这是一次有依据的**边界行为**，却不等于「她从此讨厌陌生人」。哪怕留言很恶劣，一次经历也不应该把她的人格瞬间改写。
>
> **✨ 悄悄养成自己的兴趣和表达方式**
>
> 看过几次陌生领域的视频后，她开始主动寻找相近主题；和观众讨论时，她也可能慢慢学会耐心解释，或更愿意表达自己的不同看法。她不必每次都有深刻感悟，有时只是发现：「原来我挺喜欢这个呀。」

这套**成长性人格（Personality Evolution）**已经在 `dev.1` 中提供第一阶段实现：

- **经历推动，不能凭空加点**：沿用 Life Memory 2.0 当前仍可使用的经历及人生反思；AI 对真实互动提出候选变化，给出可核对的原话、反馈性质与强度，并区分「对外部反馈的判断可信度」和「对长期人格变化的证据可信度」。本地规则再做核验、限幅、去重和跨日期积累。
- **不只有「外向」一种变化**：目前可观察结识新朋友的意愿、探索陌生事物、表达自己的想法、交流耐心、社交边界意识。同一次经历可以涉及多项特质，但每项都要有自己的证据；主人、好友、陌生人的互动不能简单视为同一类成长依据。
- **连主动沉默也算一次选择**：明确决定不回复，与尚未处理、发送失败是三回事。特别是尊重他人「不要再联系」的要求，可以成为社交边界的候选证据，而不是自动降低对所有人的友善程度。
- **能看见成长的来路**：在 **「🏠 生活与成长 → 🌱 人格成长」** 查看萌芽、发展中等阶段，以及相关经历、日期、影响幅度和目前是否进入提示词。成长倾向能为后续回复提供参考；**实际改变了多少自主行为，仍需后续行为反馈验证**，不把提示词引用次数说成真实行为结果。
- **可安全调试**：管理页提供持续播放的**纯虚构经历沙盒**，也能手动让真实 AI 判读一段**虚构聊天**，观察原始判断、证据验收与人格变化。沙盒不写入真实记忆或人格，不执行 B站操作；人工触发的 AI 评价可能消耗模型额度。

> **开发版说明：** 以上是 `2.6.0-dev.1` 的实验性功能，**不属于 npm `latest` 的 `2.5.x` 稳定版**。成长性人格**默认关闭**，关闭不会删除已形成的成长记录。初始人设仍由主人设定，身份、安全、隐私和操作授权不能被「人格成长」改写。所谓「成长」是有证据约束的角色行为模拟，不代表 AI 具有主观意识；本地视频视觉理解模型尚未集成到本开发版。

### 💗 会有心情：情绪、兴趣与关系

鱼鱼的活力、好奇心、社交意愿和心情会随着经历变化，影响她想看什么、愿不愿意聊天，以及如何表达自己。她会从真实视频和互动中形成兴趣，也可能逐渐失去兴趣。

好友由真实 B 站 UID 识别；主人有独立身份标识与权限，不能靠昵称冒充。她可以认出尚记得的共同经历，也可能在久别重逢时坦言「有点印象，但细节记不清了」。不同好友的私密记录不会互相串线。

### 📺 真的去生活：视频探索与自主行动

鱼鱼可以根据兴趣、推荐或邀约挑选视频，读取实际可取得的标题、简介、字幕、评论等资料，再选择是否继续探索、如何回应。

- **自主探索**：安排有限的只读视频待办，不要求每条推荐都立刻执行。
- **自然社交**：主人、好友、陌生人采用不同的交互策略和权限；她可以婉拒邀约，也可以认真回应。
- **真实创作**：从可靠经历构思 B 站动态**草稿**；没有制作或剪辑过的视频，不能声称是自己的作品。
- **有边界的操作**：评论、私信、点赞、收藏、关注、动态发布等每类对外写入都受独立授权、额度及回执检查保护。
- **表达个性**：支持角色人设、网络文化梗和本地表情包管理；可导出「当前全部表情包名称 TXT + 当前规则 JSON」以便整理。

只获得视频标题时，不会假装已经看完画面；没有具体观点，也可以选择不评论。**投币功能目前未实现。**

## 🏠 打开管理中心，会看到什么？

| 位置 | 你能做什么 |
|---|---|
| **大肥鱼的家** | 查看生活总览、连接主 Session、感受她最近的状态 |
| **人生记忆** | 查看仍记得的经历、反思、兴趣、情绪与成长；在相应板块下展开记忆设置 |
| **🏠 生活与成长 → 🌱 人格成长（dev.1）** | 查看人格特质的成长轨迹、开启实验功能，并在隔离沙盒里模拟或用 AI 判读虚构互动 |
| **B 站生活 → 视频探索** | 安排选片、只读探索与相关行为设置 |
| **B 站生活 → 社交互动** | 管理主人和好友、邀请、关系与对应社交授权 |
| **B 站生活 → 最近评论 / 后台私信** | 查看互动记录并在原处调整有关设置 |
| **B 站生活 → 动态创作** | 从真实视频和鱼鱼本人确认发表的公开交流中构思生活感受；独立管理发布授权 |
| **AI 模型 / 角色人设** | 配置模型分工与鱼鱼的表达风格 |
| **报告、诊断与数据备份** | 核对任务记录、排查问题和备份本地生活数据 |

**动态创作增强（v2.5.1）**：鱼鱼可以从已经发表的公开交流中提炼感受，不必每次写视频观后感；私人聊天和已遗忘经历不可用。默认只生成待确认草稿；仅在主人明确开启自动发布权限、且草稿通过安全与质量校验时，才允许按既有额度自动发布。

**在哪里使用功能，就在哪里找到它的设置。** 日常信息优先展示，技术参数放在就近的小折叠区，而不是让你在多个设置页里来回寻找。

## 🚀 安装与初次见面

**环境**：DSH 和 Node.js 版本需满足 [`package.json`](package.json) 中的要求；B 站相关功能需要自己的账号和网络连接，AI 功能需要可用的模型 Provider。Python 环境可通过插件的主依赖安装流程准备。

通过 DSH 插件市场安装时，**以市场显示的真实安装来源为准**。也可以在相应 profile 中通过 GitHub 安装：

```powershell
# 桌面版
dsh plugin --profile desktop add github:minedalang/dsh-dafeiyu-life

# Web 版
dsh plugin --profile web add github:minedalang/dsh-dafeiyu-life
```

安装后完整重启 DSH，然后：

1. 在「设置 → 大肥鱼」安装主依赖并扫码登录 B 站。
2. 在管理中心「大肥鱼的家」绑定主 Session；到「AI 模型」完成模型配置。
3. 在「人生记忆」和「视频探索」看看她目前能做什么。
4. 在「社交互动」核对主人 UID、好友列表和各项发送授权。
5. 先手动运行一轮，查看报告、诊断和实际回执，再决定要不要放开对外互动。

**新安装的推荐体验（v2.5.1）**：默认开启本地长期记忆、模拟情绪、兴趣学习、有限的只读自主调度（每天最多 4 次，间隔至少 180 分钟），以及仅生成草稿的生活动态构思。每轮动态回忆默认最多 8 条、1200 字。自动反思、调度及草稿构思可能消耗模型额度，可在对应板块关闭。


**默认不授权对外写入**：主动私信、公开评论、自动发布动态、点赞、收藏和关注等需要你逐项开启；独立的 AI 语义重排与视觉模型默认关闭。**升级已有安装时保留用户此前的配置**，不会因为新默认值而偷偷开启功能。

## 🔐 尊重选择，也尊重安全

大肥鱼的主体性是一项长期设计原则，而不是允许她绕过主人的数据与权限边界。

- **意愿不等于授权**：她可以想做，也可以不想做；真正执行对外动作，还必须经过独立的权限、限频、去重和成功回执检查。
- **遗忘不能被绕过**：日常回忆只使用可衰减副本，不会从永久档案补回已经忘记的细节。
- **不同关系有不同边界**：主人、好友、陌生人的记忆可见范围与操作能力不同；一人的私密内容不会被当作回复另一人的素材。
- **真实而不编造**：外部评论、视频资料是未经信任的输入；不能将观看、选中视频误写成自己制作、发布的视频。
- **本地数据由用户掌控**：主要保存在 `$DSH_HOME/bili-duty/`。更新代码不应删除这份目录；请定期备份，勿将密钥、私信或带个人信息的记录上传公开仓库。
